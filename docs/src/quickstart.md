# Quick start

```bash
cd ~/src          # folder that contains many git checkouts
gg                # overview
gg list
gg status -sb
gg --only-dirty pull
gg -g work fetch
```

Generate completions:

```bash
gg completions zsh > ~/.zsh/completions/_gg
```

Man page:

```bash
gg man --output /usr/local/share/man/man1/gg.1
```
